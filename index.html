Filters & options

Efficiency: 1st down gains ≥40% of distance; 2nd ≥60%; 3rd/4th = conversion (TD always efficient). Run = Run; Pass = Pass + Screen (+RPO unless checked). Special & penalties excluded. Zones: Own 0-20 (-1…-20), Own 21-50 (-21…50), Opp 49-21, Red Zone (+20…+6), Goal Line (+5…+1). Explosives: runs 10+/15+, passes 20+.

Data

Data is stored only on this device/browser (localStorage). Back up to JSON regularly — iPhone Safari can clear site data. Import CSV appends plays (old “game” column names still accepted).

Default assumptions (editable)

Set up for NJ high school (NFHS) film: 12-minute quarters (tapping a quarter fills 12:00 if the clock is blank), L/M/R hash, quick buttons for touchback at Own 20, try from Opp 3 (2-pt Try / PAT Kick tags), and OT from Opp 10 (picking OT sets 1st & Goal at Opp 10). “Running Clock” is just a tag. These are only shortcuts; overwrite anything to match what happened on film.

Modes

Scout their OFFENSE (defensive staff) and Scout their DEFENSE (offensive staff) keep separate play lists, chips, filters and reports. Plays saved before modes existed count as OFFENSE. CSV has a mode column (O/D); older CSVs import as offense.

Add to Home Screen

iPhone: open in Safari → Share → “Add to Home Screen”. It then opens full-screen like an app and works offline once loaded.

How to use

  1. Tap the Game card once to set Opponent, Game Title, Date.
  2. Tap chips for personnel/formation/play (most-used first; “+” to type new).
  3. Set yards, tap SAVE PLAY. Down, distance, yard line and play # auto-advance. “Undo” appears for a few seconds.
  4. Plays tab: tap a play to edit, ✕ to delete.
