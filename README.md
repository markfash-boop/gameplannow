# GamePlanNow

Break down their offense (or defense). Own Friday night.

A single-file, offline-capable web app for high school football coaches to tag opponent film on a phone and generate scouting reports.

- Live: https://markfash-boop.github.io/gameplannow/
- Everything is in `index.html` (vanilla JS, no build step). Data is stored only in the browser (localStorage); use Data → Backup JSON / Export CSV.
- iPhone: open the link in Safari → Share → Add to Home Screen.
